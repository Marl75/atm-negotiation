How it works

The AI negotiates; code checks the rules; a human decides

1 · CODE

Build the picture

From one late flight: arrival queue, runways, gates, crew hours, fuel, from the challenge workbook. No AI.

2 · AI

Negotiate

Each round, three separate Claude calls: Tower (ATC), Airline (Pilot), Ramp (Ground). Each sees only its own team’s data and answers in a fixed format: accept or reject, which rule, a counter-proposal.

3 · CODE

Check and choose

Fixed rules check every proposal. Code keeps the safest, then cheapest. Three rounds at most; then a solver decides and writes down why.

4 · HUMAN

Decide

The supervisor sees the plan, every check and each team’s concerns, then approves or rejects. Everything is logged.
